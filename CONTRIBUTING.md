# Contributing

1. Open an issue describing the change or security concern.
2. Keep API keys and user questions out of commits, screenshots, and logs.
3. Make the smallest focused change and update the README if behavior changes.
4. Run the checks in `.github/workflows/ci.yml` before opening a pull request.
5. Explain any new network access, stored data, moderation behavior, or secret.

Do not weaken citation, moderation, request-size, or secret-handling safeguards
without documenting the reason and the resulting risk.
